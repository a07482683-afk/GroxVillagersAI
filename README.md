# GroxVillagersAI

**Minecraft Java 1.20.1 · Fabric · Java 17 · Offline**

Первый прототип автономных жителей:
- индивидуальная смелость, страх, доверие и настроение;
- реакция на враждебных мобов: жители с низкой смелостью стараются убежать;
- простые русские диалоги через команду `/grox <сообщение>`;
- Shift + ПКМ по жителю показывает его характеристики;
- память жителей сохраняется в данных мира и переживает перезапуск.

## Сборка
Открой вкладку **Actions** на GitHub. После успешной сборки скачай артефакт `GroxVillagersAI-1.20.1`, распакуй ZIP и помести JAR в папку `mods`.

Требуется Minecraft 1.20.1, Fabric Loader 0.15.x или новее, Fabric API для 1.20.1 и Java 17.

## Ограничения первой версии
Это офлайн-прототип на правилах, а не большая языковая модель: он не понимает произвольные вопросы как ChatGPT, не заменяет ванильную модель жителей и пока не реализует полноценные профессии, торговлю, бой или свободное управление инвентарём.
