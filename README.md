# GroxVillagersAI

**Minecraft Java 1.20.1 · Fabric · Java 17 · Offline**

Мод постепенно расширяется. Текущие функции:
- индивидуальные параметры жителей: смелость, доверие, страх и настроение;
- реакция на враждебных мобов: жители с низкой смелостью стараются убежать;
- память диалогов сохраняется в данных мира;
- **ЛКМ по жителю** — начать разговор, не нанося ему урон;
- **Shift + ЛКМ** — посмотреть характер, страх, доверие, настроение и число разговоров;
- **ПКМ по жителю** — обычная ванильная торговля Minecraft;
- **Shift + ПКМ** — быстрый просмотр характеристик;
- команда **/grox <сообщение>** — текстовый диалог с ближайшим жителем.

## Управление
- ЛКМ: короткая реплика жителя.
- Shift + ЛКМ: характеристики.
- ПКМ: ванильное окно торговли (если у жителя есть профессия и он может торговать).
- Shift + ПКМ: характеристики.
- Введи в чат: `/grox привет, как дела?` — получить ответ от ближайшего жителя.

## План следующих этапов
1. **Диалоги и память:** больше разнообразных ответов, запоминание тем и отношений с игроком.
2. **Настоящее общение:** обработка сообщений игрока, контекстные ответы и возможность нескольким жителям вступать в беседу.
3. **Личности и эмоции:** разные характеры, страх, радость, любопытство, доверие и реакции на поступки игрока.
4. **Самостоятельная жизнь:** распорядок дня, потребности, цели, исследование деревни и взаимодействие с предметами.
5. **Социальная система:** дружба, группы жителей, отношения и совместные решения.
6. **Оборона и опасности:** игровые реакции на угрозы, помощь друг другу и безопасное поведение жителей.
7. **Оружейный игровой этап (позже):** отдельные фантазийные игровые предметы — RPG-пускатель, пистолет и снайперская винтовка; собственные 3D-модели, игровые рецепты из доступных Minecraft-ресурсов и баланс. **Торговца оружием добавлять не будем.** Этот этап пока только в плане; оружие и модели ещё не реализованы.

## Сборка
Открой вкладку **Actions** на GitHub. После успешной сборки скачай артефакт `GroxVillagersAI-1.20.1`, распакуй ZIP и помести JAR в папку `mods`.

Требуется Minecraft 1.20.1, Fabric Loader 0.15.x или новее, Fabric API для 1.20.1 и Java 17.

## Ограничения
Диалоги сейчас работают по набору правил и фраз, это ещё не свободная языковая модель. Не все будущие этапы уже реализованы. В частности, новые системы жизни, 3D-модели оружия и рецепты появятся только в последующих обновлениях.
