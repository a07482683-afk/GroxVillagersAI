# GroxVillagersAI

**Minecraft Java 1.20.1 · Fabric · Java 17 · Offline · Mod version 0.1.9**

## Уже реализовано
- У каждого жителя индивидуальные смелость, доверие, страх, настроение, общительность и любопытство.
- Состояние эмоции (нейтральное, радость, грусть, страх, злость, удивление) сохраняется в памяти жителя; видимое отображение эмоций будет подключено через слой рендера.
- Долговременная память характеристик и последних событий сохраняется в мире.
- ЛКМ по жителю не запускает диалог и не засоряет чат.
- Shift + ЛКМ показывает характеристики один раз, только в творческом режиме.
- ПКМ — ванильная торговля.
- Жители постепенно становятся общительнее, если проводят время рядом друг с другом.
- Жители могут самостоятельно произносить короткие комментарии, когда игрок проходит рядом; вероятность зависит от общительности и любопытства.
- Первые автономные реплики доступны на русском, таджикском, английском, испанском, французском, немецком, португальском, арабском, китайском, хинди и японском.
- Реакция на враждебных мобов: жители с низкой смелостью стараются отойти от угрозы.
- Ответы собираются из пяти независимых наборов фраз. Их сочетания дают **10 027 008 вариантов**. Они создаются процедурно офлайн, а не хранятся миллионами отдельных строк.

## Управление
- F при наведении на жителя: попросить его остановиться и поговорить.
- ПКМ: обычная торговля Minecraft.
- Shift + ЛКМ: характеристики только в творческом режиме.
- Выбрать язык автономных реплик: `/groxlang ru`, `/groxlang tg`, `/groxlang en`, `/groxlang es`, `/groxlang fr`, `/groxlang de`, `/groxlang pt`, `/groxlang ar`, `/groxlang zh`, `/groxlang hi`, `/groxlang ja`.

## Сборка
GitHub Actions собирает мод автоматически на Java 17. После успешного запуска открой **Actions**, выбери последнюю сборку и скачай артефакт `GroxVillagersAI-1.20.1`. ZIP нужно распаковать; JAR положить в папку `mods`.

Требуется Minecraft 1.20.1, Fabric Loader 0.15.x или новее, Fabric API для 1.20.1 и Java 17.

## Важно
Диалоги — офлайн-система на правилах и комбинировании фраз, а не полноценная языковая модель ChatGPT. Количество сочетаний превышает десять миллионов, но ответы могут иногда звучать неестественно.


## Ordinary chat reactions (new)
- Villagers listen to normal player chat; no `/grox` command is needed for supported phrases.
- Nearby villagers make separate response decisions based on bravery, trust, fear, curiosity and sociability.
- Supported physical reactions at this stage: looking toward the player and turning left.
- Requests to wave, raise a hand or sit are recognized, but those limb/pose animations are not implemented yet. They require a custom villager model and animation renderer.
- To avoid flooding chat, at most four nearby villagers answer one message.

## Диалоговая система 0.1.9
- Жителям больше не обязательно писать «жители» или «привет»: обычное сообщение игрока может вызвать ответ жителей в радиусе 12 блоков.
- Добавлены тематические ответы о знакомстве, доме, делах, мнении, помощи, работе, еде, ресурсах, торговле, погоде, опасностях, настроении, благодарности и извинениях.
- Житель учитывает настроение, страх, доверие и любопытство; реплики игрока сохраняются в его долговременной памяти.
- Чтобы чат не засорялся, на одно сообщение отвечают максимум три жителя.
- Диалоги остаются офлайн-системой на правилах и комбинировании фраз. Это не полноценная языковая модель и не бесконечный словарь.


## Локальные диалоги 0.1.9
- Расширено распознавание вопросов о личности: «кто ты», «ты кто такой», «расскажи о себе», «представься» и похожие формулировки.
- Добавлены отдельные ответы о характере, интересах и игровых воспоминаниях жителя.
- Ответ на вопрос о памяти использует последнее сохранённое событие, а не случайную общую фразу.
- Интеллект остаётся локальным и не требует облачного API. Это контекстная система правил, а не большая языковая модель.
- Голосовая озвучка слов пока не включена: для неё нужен отдельный локальный TTS-компонент и проверка совместимости с Windows 7.


## Локальный голос жителей 0.1.9
- Добавлен клиентский модуль озвучки сообщений жителей через внешний локальный eSpeak.
- Голос генерируется на компьютере игрока и воспроизводится только у него; интернет и облачный API не нужны.
- По умолчанию мод ищет `espeak.exe` в PATH и стандартных папках установки. Если программа установлена в другом месте, укажи полный путь в `config/groxvillagersai-voice.properties`.
- Для Windows 7 подходит классический eSpeak 1.48.04; Microsoft указывает совместимость этой версии с Windows 7. Новые версии eSpeak NG требуют Windows 8 или новее.
- Настройка голоса: замедленная речь, пониженная высота тона и эффект `+croak`, чтобы приблизить звучание к стилизованному голосу жителя.
- Язык выбирается по письменности текста: кириллица — русский (приближённо также для таджикского), латиница — английский, арабская, китайская, японская и деванагари — соответствующие голоса. Для языков на латинице пока используется английский голос.
- Если eSpeak не установлен, текстовые диалоги продолжают работать как обычно; мод не скачивает и не устанавливает сторонние программы самостоятельно.
