# GroxVillagersAI

**Minecraft Java 1.20.1 · Fabric · Java 17 · Offline**

Мод постепенно расширяется. Текущие функции:
- индивидуальные параметры жителей: смелость, доверие, страх и настроение;
- реакция на враждебных мобов: жители с низкой смелостью стараются убежать;
- память диалогов сохраняется в данных мира;
- **ЛКМ по жителю** — начать разговор, не нанося ему урон;
- **Shift + ЛКМ** — посмотреть характер, страх, доверие, настроение и число разговоров;
- **ПКМ по жителю** — обычная ванильная торговля Minecraft;
- **Shift + ПКМ** — быстрый просмотр характеристик;
- команда **/grox <сообщение>** — текстовый диалог с ближайшим жителем.

## Управление
- ЛКМ: короткая реплика жителя.
- Shift + ЛКМ: характеристики.
- ПКМ: ванильное окно торговли (если у жителя есть профессия и он может торговать).
- Shift + ПКМ: характеристики.
- Введи в чат: `/grox привет, как дела?` — получить ответ от ближайшего жителя. Ответы разнообразятся в зависимости от настроения, доверия и страха.

## Этапы разработки
1. Диалоги и долговременная память — базовая версия готова; добавлены разные ответы и изменение доверия/настроения.
2. Личности и эмоции — базовые параметры есть; расширение реакций продолжается.
3. Самостоятельная жизнь — следующий этап: распорядок, потребности и цели.
4. Социальная система — следующий этап: дружба, группы и совместные решения.
5. Реакции на опасности — базовая реакция на враждебных мобов есть; далее планируется помощь жителей друг другу.

## Сборка
Открой вкладку **Actions** на GitHub. После успешной сборки скачай артефакт `GroxVillagersAI-1.20.1`, распакуй ZIP и помести JAR в папку `mods`.

Требуется Minecraft 1.20.1, Fabric Loader 0.15.x или новее, Fabric API для 1.20.1 и Java 17.

## Ограничения
Диалоги работают офлайн по набору правил и фраз, это пока не свободная языковая модель уровня ChatGPT. ПКМ оставлен ванильной торговле, чтобы не ломать обмены. Для разговора используй ЛКМ или команду `/grox <сообщение>`. Панель характеристик открывается через Shift + ЛКМ или Shift + ПКМ только в творческом режиме.
